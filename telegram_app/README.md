# ONEFLOW в Telegram — мини-приложение

Страница `oneflow.art/tg`, открывается из бота. Код лежит в основном репозитории (`src/tg/`, `tg.html`,
`supabase/functions/tg-app`, `deploy/selfhost/telegram/`); здесь — скриншоты экранов и скрипты, которыми они сняты.

| Файл | Что это |
|---|---|
| `app-1.jpg … app-6.jpg` | настоящие скриншоты 18 экранов (образцовые данные, сервер разработки) |
| `shots.cjs`, `board.cjs` | съёмка экранов и раскладка по телефонам |

Экраны: главный, картинка, качество, видео, идёт генерация, результат, «В чат», галерея, баланс (звёзды),
нехватка кредитов, пригласить друга, Casting Engine, уведомления, новый пользователь, English.
