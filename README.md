# ONEFLOW — посадочная страница

Статичный лендинг AI-платформы ONEFLOW: тёмная тема, макет собран по дизайну —
десктоп и мобильная версия.

## Структура

```
index.html        разметка страницы + SVG-спрайт иконок
styles.css        стили и брейкпоинты
script.js         меню, появление блоков, отрисовка связей между нодами
assets/
  headphones.svg  иллюстрация товара для превью креативов
  fonts.css       @font-face для самостоятельно захостенных шрифтов
  fonts/          Inter + Instrument Serif (latin, latin-ext, cyrillic)
```

## Как открыть

Достаточно открыть `index.html` в браузере. Для локального сервера:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Сборка и зависимости не нужны — обычный HTML/CSS/JS.

## Секции

1. Hero — заголовок, CTA и мокап редактора с нодами
2. Ноды и адаптация — один исходник → форматы 1:1, 9:16, 16:9, свой размер
3. Сравнение креативов — карточка «Пример анализа»
4. One Launch — из фото в карточки товара
5. Остальные задачи — фото/видео, тексты, музыка, стратегия
6. Экономия бюджета + финальный CTA

## Технические решения

- **Мокап редактора.** На десктопе ноды позиционируются в процентах внутри
  `.canvas` (контейнер с `container-type: inline-size`), размеры текста заданы
  в `cqw` — блок масштабируется целиком вместе с шириной. Связи между нодами
  рисует `script.js` по реальным координатам портов, поэтому линии не
  расходятся при любом размере окна. На экранах до 900px ноды выстраиваются в
  колонку, три результата — в ряд, SVG-связи скрываются.
- **Адаптив.** Брейкпоинты 1080 / 960 / 900 / 760 / 560px. Горизонтального
  скролла нет на ширинах от 320px.
- **Шрифты** захостены локально (без обращения к Google Fonts), подключены
  только latin и cyrillic сабсеты.
- **Доступность.** Skip-link, `aria-expanded` у бургера, закрытие меню по Esc,
  видимый фокус, поддержка `prefers-reduced-motion`.

## Что заменить на реальные данные

- `assets/headphones.svg` — на фото товара;
- ссылки `#start`, `#features`, `#support`, `#pricing` — на реальные страницы;
- тексты в секциях и метатеги `og:*` в `<head>`.
