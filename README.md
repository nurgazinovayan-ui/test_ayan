# nurgazinov.com

Портфолио арт-директора: тёмный «кинематографичный» одностраничник с 3D-кинозалом на three.js,
страницами проектов и админкой для редактирования контента без кода.

- **Сайт:** https://nurgazinov.com
- **Админка:** https://nurgazinov.com/admin/

---

## Что можно менять в админке

| Раздел админки | Что меняется на сайте |
|---|---|
| Главная страница → **1. Видео на первом экране** | шоурил на экране кинозала и его постер |
| Главная страница → **2. Обо мне** | имя, портрет, текст, город, цифры |
| Главная страница → **3. Контакты** | e-mail, телефон, соцсети |
| Главная страница → **4. SEO** | заголовок вкладки, описание для Google, картинка превью ссылки |
| **AI-фильмы** | добавить / удалить / переставить фильмы в разделе «Short films made with AI» |
| **Проекты** | плитки в «Selected work» + у каждого проекта своя страница `/projects/<адрес>/` с текстом, фото, галереями, видео и цитатами |
| **Логотипы клиентов** | добавить / удалить / переставить логотипы в бегущей строке |

У каждого поля загрузки в админке написано, какого формата, размера и веса должен быть файл.

**Как это работает:** админка ([Decap CMS](https://decapcms.org)) сохраняет изменения коммитом в этот
GitHub-репозиторий, Netlify замечает коммит и за ~1 минуту пересобирает сайт. Сервер и база данных не нужны.

## Деплой на nurgazinov.com (один раз)

### 1. Слить код в `main`
Админка пишет в ветку `main`, а Netlify публикует её же. Слейте ветку с этими изменениями в `main`.

### 2. Создать сайт на Netlify
1. Зарегистрируйтесь на https://app.netlify.com (удобнее всего через GitHub).
2. **Add new project → Import an existing project → GitHub** → выберите репозиторий `nurgazinovayan-ui/test_ayan`.
3. Ветка — `main`. Настройки сборки подтянутся из `netlify.toml` сами
   (`npm run build`, папка `dist`). Нажмите **Deploy**.
4. Через пару минут сайт откроется по адресу вида `something.netlify.app` — проверьте его.

### 3. Подключить домен nurgazinov.com
1. В Netlify: **Domain management → Add a domain** → `nurgazinov.com` (www добавится сам).
2. У регистратора домена пропишите DNS одним из двух способов:
   - **Проще:** сменить NS-серверы домена на те 4, что покажет Netlify (Netlify DNS);
   - **или** оставить DNS у регистратора и добавить записи:
     - `A` для `@` → `75.2.60.5`
     - `CNAME` для `www` → `<ваш-сайт>.netlify.app`
3. Подождите, пока DNS обновится (от 10 минут до суток). HTTPS-сертификат Netlify выпустит автоматически
   (**Domain management → HTTPS**).

### 4. Включить вход в админку (через GitHub)
1. GitHub → **Settings → Developer settings → OAuth Apps → New OAuth App**:
   - Application name: `nurgazinov.com admin`
   - Homepage URL: `https://nurgazinov.com`
   - Authorization callback URL: `https://api.netlify.com/auth/done`

   Создайте, затем нажмите **Generate a new client secret**. Скопируйте Client ID и Client Secret.
2. Netlify → ваш сайт → **Project configuration → Access & security → OAuth → Install provider → GitHub**,
   вставьте Client ID и Client Secret.
3. Откройте https://nurgazinov.com/admin/ → **Войти через GitHub**. Готово.

Войти может только тот, у кого есть права на запись в репозиторий — посторонние ничего не изменят.

## Разработка локально

Нужен Node.js 20+.

```bash
npm install
npm run dev          # собрать и открыть http://localhost:8080
```

Админка локально, без GitHub (изменения пишутся прямо в файлы на диске):

```bash
npm run cms          # в одном терминале
npm run dev          # в другом → http://localhost:8080/admin/ → «Войти»
```

После правок контента локально — снова `npm run dev`, чтобы пересобрать.

## Структура

```
content/                    ← всё, что редактируется в админке
  settings/hero.json        видео на первом экране
  settings/about.json       «Обо мне», имя, город
  settings/contact.json     контакты и соцсети
  settings/seo.json         SEO и картинка превью
  films.json                AI-фильмы
  logos.json                логотипы клиентов
  projects/*.json           проекты (один файл = одна плитка + одна страница)
src/                        ← код и оформление
  index.template.html       разметка главной (метки <!--@...--> и {{...}} заполняет сборка)
  css/styles.css            все стили (включая страницы проектов)
  css/fonts.css             подключение шрифтов (локальные .woff2)
  js/main.js                поведение: 3D-зал, лоадер, фильмы, автоплей видео
  admin/config.yml          поля админки, подписи и подсказки по форматам
  assets/                   шрифты, видео, картинки, логотипы, three.js
  assets/uploads/           файлы, загруженные через админку
scripts/build.mjs           сборка: content + src → dist/
scripts/serve.mjs           локальный сервер для dist/
netlify.toml                настройки Netlify
```

### Заметки
- **Hero-видео** натягивается на экран кинозала (пропорция 2.45:1) в режиме «cover»: видео любой
  пропорции обрезается по центру, а не растягивается.
- **Логотипы** выводятся CSS-маской по альфа-каналу файла, поэтому любой SVG/PNG с прозрачным фоном
  автоматически становится одноцветным под тему сайта.
- **Сетка Selected work** повторяет асимметричный шаблон из дизайна каждые 7 проектов; обложки
  обрезаются под форму плитки (`object-fit: cover`).
- **Шрифты** лежат в проекте (`src/assets/fonts`, подключение — `src/css/fonts.css`), к Google Fonts
  сайт не обращается. Archivo и Caveat — только латиница: если вписать в админке текст на кириллице,
  он отобразится запасным шрифтом (Helvetica/Arial). Проверьте, что лицензия Dx Playhigh и Dx Burst
  разрешает использование на сайте.
- three.js — UMD-сборка r159 (устаревшая, но рабочая). При переходе на сборщик (Vite) стоит перейти на ES-модули.
