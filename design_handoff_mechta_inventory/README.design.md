# Handoff: Mechta Marketing Inventory 2026 — посадочная + бриф

## Overview
Одностраничный лендинг маркетингового инвентаря Mechta.kz для вендоров. Пользователь (1) выбирает рекламные услуги из каталога по категориям, (2) заполняет пошаговый бриф. Выбранные услуги + ответы брифа собираются в текст и отправляются вебхуком (Make.com) на почту.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML** (прототип с реальным поведением), а не продакшн-код. Задача — **воссоздать дизайн в целевом окружении** (React/Next.js, Vue, Tilda-блок и т.д.) по его паттернам. Если окружения нет — рекомендуется Next.js + React + Tailwind (или CSS-modules), canvas-эффекты переносятся как есть в отдельные компоненты.

Открыть референс: `Mechta Inventory 2026.dc.html` через любой локальный сервер (`npx serve .`) — файл подключает `support.js` (рантайм прототипа, в продакшн не переносить).
Вся логика и данные — в `<script data-dc-script>` внизу файла: класс `Component` (React-подобный: `state`, `setState`, `componentDidMount`), метод `renderVals()` отдаёт значения в шаблон. Шаблон — разметка между `<x-dc>…</x-dc>` с `{{ }}`-подстановками, `<sc-for>` (цикл) и `<sc-if>` (условие).

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, анимации и взаимодействия. Воспроизводить пиксель-в-пиксель.

## Screens / Sections (сверху вниз)

### 0. Прелоадер (fixed, z-index 1000)
- Фон `#000000`, по центру canvas 260×(5·30+4·5+50) px, на мобиле `min(260px, 80vw)`.
- Пиксельная воронка из 5 трапеций (ширины 1 → .845 → .69 → .535 → .38 → низ .25, ×0.72 от 260px), пиксель 6px (квадрат 5px + зазор 1px), белые с лёгким мерцанием (alpha 0.86–1, sin).
- Каждые 420ms следующая секция «перекрашивается» белый → `#FF0080` россыпью: каждому пикселю случайный порог, прогресс 0→1 за 450ms.
- Над воронкой пиксельная подпись (шрифт 700 17px, letter-spacing 2px, сэмплинг 2px, цвет `#FF0080`), меняется по этапам: ОСВЕДОМЛЕННОСТЬ → ИНТЕРЕС → РЕШЕНИЕ → ДЕЙСТВИЕ → ПОКУПКА; новое слово проявляется россыпью за 260ms.
- После 5-го этапа +450ms → fade-out opacity 600ms, затем удалить из DOM. Пока виден — `body { overflow: hidden }`.

### 2. Hero
- `section`: `min-height: clamp(480px, 72vh, 760px)`, flex-column, center, gap 8px, padding 64px 32px, overflow hidden.
- **Фон-видео** `hero-video.webm` (muted, loop, autoplay, cover), `opacity: 0.9; filter: brightness(0.92) saturate(1.15)`; поверх градиент `linear-gradient(to bottom, rgba(9,9,11,.2), rgba(9,9,11,0) 40%, rgba(9,9,11,.85))`.
- **Canvas-«занавес»** поверх видео: сетка 20px клеток `#09090B`, проявление снизу вверх за 3.2s (easeInOutQuad), у каждой клетки порог = (1 − y/rows)·0.62 + rand·0.38, ширина фронта 0.18, клетка открывается в 4 ступени (alpha 1 → .75 → .5 → .25 → 0, smoothstep, квантованный). Стартует только после ухода прелоадера.

- **Надпись** «Make marketing / great again» — 2 строки, `font-size: clamp(24px, 3.2vw, 40px)`, 700, пиксельная (сэмплинг 3px), белая.
- **Большое лого** `mechta-logo-hero.svg`, `width: min(720px, 100%)`, aspect 1536/1024, отрицательные margin `calc(-1 * min(84px, 11.5vw))` сверху и `calc(-1 * min(72px, 10vw))` снизу (у SVG прозрачные поля). Рисуется пикселями 6px на canvas.
- **«by» + маленькое лого** в ряд, gap 12px: «by» 22px пиксельное, `mechta-logo-small.svg` 148px.
- **CTA «ЗАПОЛНИТЬ БРИФ»** (margin-top 40px): `clamp(32px, 4.4vw, 56px)`, 700, uppercase, letter-spacing .06em, пиксели 5px; по бокам пиксельные указательные пальцы (матрица 14×9, `#FF4D9D`) направлены в текст, «тычут» (смещение 0/1/2/1 × 5px, 5 fps). Текст «подпрыгивает» по-8-битному (0/−1/−1/0 × 5px).
  - Hover: курсорный круг сжимается (фон 50→14px, лого 40→13px), по буквам бежит розовая волна (`sin(t·7 − x·0.015)`, белый → `#FF4D9D`), пальцы пульсируют, под текстом из центра выезжает пиксельное подчёркивание (5px клетки, розовое).
  - Click: раскрывает секцию 3 и плавно скроллит к ней.
- Курсор возле пиксельных лого/надписей: пиксели розовеют и отталкиваются (push = e²·22px), кроме CTA (там только пульс).

Все пиксельные надписи: реальный DOM-текст остаётся (для SEO/a11y), но `color: transparent`; canvas сэмплирует текст через offscreen `fillText` + `getImageData`.
