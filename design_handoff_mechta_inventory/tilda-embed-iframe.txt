ВСТАВКА В ТИЛЬДУ

В блок T123 идёт ТОЛЬКО этот код (~1 КБ). Сам файл
"Mechta Inventory 2026.html" в блок вставлять нельзя: в T123 лимит около
100 000 байт, а файл — 262 КБ, Тильда ответит «слишком много контента
в блоке». Файл нужно разместить на хостинге и дать сюда ссылку на него.

ГДЕ РАЗМЕСТИТЬ ФАЙЛ
  Тильда не хранит произвольные .html — своего файлового хостинга под это
  у неё нет. Варианты:

  1. Netlify Drop — быстрее всего, без аккаунта и без гита:
     открыть https://app.netlify.com/drop и перетащить туда файл.
     Ссылка вида https://<случайное-имя>.netlify.app/ готова сразу.

  2. GitHub Pages — если файл ведётся в репозитории:
     он уже лежит в docs/index.html. Включить в репозитории
     Settings -> Pages -> Source: ветка main, папка /docs.
     Ссылка: https://<логин>.github.io/<репозиторий>/

  3. Любой свой хостинг / S3 / Cloudflare Pages.

  НЕ подойдут Google Drive и Яндекс.Диск: публичная ссылка отдаёт файл
  на скачивание или страницу-просмотрщик, а не сам HTML, — в iframe
  это не работает.

Ниже заменить ССЫЛКА_НА_ФАЙЛ на полученный URL.
================================================================================

<div style="width:100%">
  <iframe src="ССЫЛКА_НА_ФАЙЛ" title="Mechta Inventory 2026"
          id="mechta-inv-frame" allow="clipboard-write"
          style="width:100%;border:0;display:block;min-height:1200px"></iframe>
</div>
<script>
(function () {
  var f = document.getElementById('mechta-inv-frame');

  // Страница сама сообщает свою высоту через postMessage: читать
  // contentDocument нельзя — файл лежит на другом домене, и браузер
  // запретит доступ (именно на этом молча ломался прежний вариант).
  window.addEventListener('message', function (e) {
    var d = e.data;
    if (!d || typeof d.__mechtaHeight !== 'number') return;
    if (f.contentWindow && e.source !== f.contentWindow) return;  // чужой iframe
    f.style.height = (d.__mechtaHeight + 24) + 'px';
  });
})();
</script>
