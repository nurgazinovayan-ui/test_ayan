ВСТАВКА В ТИЛЬДУ

В блок T123 идёт только этот код. Сам HTML-файл в блок вставлять нельзя:
лимит T123 около 100 000 байт, а страница — около 850 КБ.

ЧТО ВЫКЛАДЫВАТЬ НА ХОСТИНГ
  Папку dist/ целиком: index.html (и его копия «Mechta Inventory 2026.html»)
  плюс hero-video.webm. Видео должно лежать рядом с HTML — без него хиро
  останется без фона, но всё остальное работает.

  1. Netlify Drop — https://app.netlify.com/drop, перетащить папку dist.
     Чтобы адрес не поменялся, выкладывать в тот же сайт: Deploys -> перетащить.
  2. GitHub Pages — содержимое dist уже лежит в docs/ репозитория.
  3. Свой сервер — скопировать содержимое dist.

  Google Drive и Яндекс.Диск не подойдут: они не отдают HTML как страницу.

ПОЧЕМУ IFRAME ВЫСОТОЙ В ЭКРАН
  Новый дизайн — полноэкранная страница со своей прокруткой: липкая панель
  брифа, прокрутка к форме по кнопке «Заполнить бриф», полноэкранный
  прелоадер. Всё это работает, только если страница прокручивается сама —
  поэтому iframe занимает ровно экран, а прокрутка идёт внутри него.
  Лучше всего, если на странице Тильды кроме этого блока ничего нет —
  тогда снаружи она неотличима от обычной.

  height: 100dvh учитывает адресную строку мобильных браузеров; строка
  с 100vh перед ней — запасная для браузеров, где dvh ещё нет.

ПОЛОСА ПРОКРУТКИ
  Внутри страницы полоса скрыта сборкой. Строки <style> ниже прячут полосу
  самой страницы Тильды — она появляется, если страница хоть немного выше
  экрана: из-за отступов блока, других блоков или плашки «Made on Tilda».
  Прокрутка при этом работает. Если на странице есть другие блоки и их
  полоса нужна, удалите <style>. И лучше поставить блоку T123 отступы
  сверху и снизу 0 (Настройки блока) — тогда лишней высоты не будет вовсе.

Ниже заменить ССЫЛКА_НА_ФАЙЛ на адрес выложенного index.html.
================================================================================

<style>
  html, body { scrollbar-width: none; }
  html::-webkit-scrollbar, body::-webkit-scrollbar { display: none; }
</style>
<iframe src="ССЫЛКА_НА_ФАЙЛ" title="Mechta Inventory 2026"
        id="mechta-inv-frame" allow="clipboard-write"
        style="display:block;width:100%;border:0;height:100vh;height:100dvh"></iframe>
