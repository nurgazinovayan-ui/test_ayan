# ONEFLOW в Claude — коннектор (MCP)

Человек добавляет ONEFLOW в настройках Claude, входит в свой аккаунт на `oneflow.art/connect`, нажимает
«Разрешить» — и дальше просит Claude обычными словами: картинка, видео, галерея, баланс. Код лежит в основном
репозитории (`supabase/functions/mcp`, `supabase/functions/mcp-auth`, `supabase/mcp-widgets`, `src/connect`,
`deploy/selfhost/claude-connector`); здесь — картинки и скрипт, которым собраны листы.

| Файл | Что это |
|---|---|
| `claude-1.jpg` | подключение: адрес коннектора, вход, страница разрешения |
| `claude-2.jpg` | в чате: картинка, видео в работе, готовое видео (окошко настоящее, рамка чата — макет) |
| `claude-3.jpg` | галерея, нехватка кредитов, телефон в тёмной теме на английском |
| `board.cjs` | раскладка скриншотов по листам |
